# 五子棋程序设计 2026

12×12 自由五子棋课程项目。当前提交实现为自研 Alpha-Beta / PVS 搜索、64 通道量化根策略网络与 2098 条精确局面开局谱。

**唯一当前提交入口：[src/brain.cpp](src/brain.cpp)。** 单文件 C++17，模型和棋谱均已内嵌，运行时不依赖 Python、GPU、网络或模型文件。

截至 **2026-11-05 21:19（上海）** 保存的第 11 版评测快照：**第 8 名，158 分，45 场胜、5 场负、23 场平**。这是历史记录，排名会随对手版本更新变化。此前冲击第一名的目标尚未达到；自动优化与提交任务已停止。

## 构建与验证

需要 C++17 编译器和 Python 3 标准库。默认构建不使用训练环境。

```sh
make
make test
```

程序生成在 `build/release/brain`。也可以直接编译：

```sh
c++ -std=c++17 -O2 src/brain.cpp -o brain
```

评测时只提交 `src/brain.cpp`，选择 **G++ / C++17**。源码和编译产物的限制分别为 1 MiB，不是二者相加。源码为 314981 字节。`make check-size` 检查本机产物大小及源码 SHA256；Linux 构建与同套测试由 GitHub Actions 运行。

`make test` 覆盖棋盘增量缓存及撤销、浅层参考搜索与 TT 窗口、VCT 证明边界、导出器解析及正式协议和有状态 probe 一致性。测试不下载数据、不训练模型、不提交评测；浅层正确性与短协议测试不等于整体棋力保证。

## 版本管理

`main` 保存整理后的项目，标签 `submission-11` 固定本次归档的正式版本。此前未使用 Git 的开发过程通过历史源码清单和进展文档记录，没有伪造逐次提交历史。后续实验在 `codex/实验名称` 分支中进行，每次提交说明改动、对照结果和是否采用；正式版本另打标签，不再不断复制新的根目录文件。

## 当前算法

1. 先处理己方立即成五和对手立即成五挡点。
2. 按完整棋盘和行动方查询开局谱，支持 8 种旋转翻转，不交换黑白。
3. 脱谱后用 c64 模型和启发式融合根候选，保留己方活三和四威胁。
4. 使用有预算的 VCF、完整防守分支 VCT 和迭代加深 PVS；通过 TT、history、killer 与增量棋形缓存减少重复计算。
5. 只采纳完整迭代。默认单手上限 1100ms，按剩余空位和 85 秒搜索预算自适应缩短。

最大普通深度 18，威胁延伸上限 8。普通内部候选为启发式前 12 加己方成四点；实验性的内部活三并集尚未合入。有限搜索中的未知结果不能当成安全或已证胜。

## 棋谱工具

复制 `config/example.json` 为 `config/local.json` 并填写自己的平台信息；后者不会被 Git 跟踪。命令行参数优先，不需要浏览器 Cookie。

```sh
python3 scripts/export_games.py --submission 'http://judge.example:18080/submission/SUBMISSION_ID'
python3 scripts/judge_status.py --base-url 'http://judge.example:18080' --user-id USER_ID --queue
python3 scripts/compare_submissions.py --baseline OLD_ID --challenger NEW_ID
```

导出到 `data/<id>/` 并生成棋谱 ZIP。完整比较前检查 `index.json` 的 pending 和 errors 均为零。详情页保存的历史对手版本与榜单现役版本池不同，应按提交 ID 和执色配对。
